  ### Step 1: Verify Relationships (Model View)

  In Power BI, click the Model view icon on the far-left sidebar (the third icon with small boxes connected by lines).

  Power BI often auto-detects relationships, but let's confirm the Star Schema looks like a star with fact_inspections
  in the center:

  1. Look for fact_inspections in the middle.
  2. Ensure these 4 relationship lines exist connecting the dimension tables to fact_inspections:
      • dim_date (date_key) ─── 1 to Many (1:*) ───> fact_inspections (date_key)
      • dim_establishment (establishment_key) ─── 1 to Many (1:*) ───> fact_inspections (establishment_key)
      • dim_geography (geography_key) ─── 1 to Many (1:*) ───> fact_inspections (geography_key)
      • dim_facility_type (facility_type_key) ─── 1 to Many (1:*) ───> fact_inspections (facility_type_key)
  3. Also connect fact_violations (if imported):
      • fact_inspections (inspection_id) ─── 1 to Many (1:*) ───> fact_violations (inspection_id)


  (Tip: If any line is missing, simply drag the key column name from the dimension table and drop it onto the matching
  column in fact_inspections.)
  ──────
  ### Step 2: Create the 5 Core DAX Measures

  Switch to Report view (the top icon on the far-left sidebar).

  To keep our formulas organized, let's create a dedicated Measures table:

  1. In the top ribbon, click Enter Data (under the Home tab).
  2. Name the table _Measures and click Load.
  3. Now, right-click _Measures in the right-side Data pane and select New measure.

  Add these 5 standard business measures one by one:

  #### Measure 1: Total Inspections

    Total Inspections = COUNTROWS('fact_inspections')

  #### Measure 2: Total Failed Inspections

    Total Failures = CALCULATE(
        COUNTROWS('fact_inspections'),
        'fact_inspections'[is_failure] = TRUE()
    )

  #### Measure 3: Overall Pass Rate (%)

    Pass Rate % =
    DIVIDE(
        CALCULATE(COUNTROWS('fact_inspections'), 'fact_inspections'[results] IN {"Pass", "Pass w/ Conditions"}),
        [Total Inspections],
        0
    )

  (After pasting, click the % icon in the top Measure tools ribbon and set decimal places to 1).

  #### Measure 4: Failure Rate (%)

    Failure Rate % =
    DIVIDE([Total Failures], [Total Inspections], 0)

  (Format as % with 1 decimal place).

  #### Measure 5: Total Priority/Critical Violations

    Total Priority Violations = SUM('fact_inspections'[priority_violations_count])

 ## Page 1 has 6 Sections to build:

   #  │ Section              │ Visual Type              │ Key Fields
  ────┼──────────────────────┼──────────────────────────┼─────────────────────────────────────────────────────────────
   1  │ Header               │ Text Box + Shape         │ Static branding
   2  │ 5 KPI Cards          │ Card                     │ All 5 _Measures DAX measures
   3  │ Monthly Trend        │ Line Chart               │ dim_date[year/month] × [Failure Rate %]
   4  │ Results Distribution │ Donut Chart              │ fact_inspections[results] × [Total Inspections]
   5  │ Top Facilities       │ Bar Chart                │ dim_facility_type[standardized_category] × [Total Failures]
   6  │ Slicers              │ Slicer (Tile + Dropdown) │ Year, Risk Level, Facility Type

  ### Key design decisions tailored to your schema:

  • Red #DC2626 for failure metrics, Green #16A34A for pass metrics — maps directly to your is_failure BIT field
  • Donut slices use all 4 distinct values in your fact_inspections[results] column (Pass, Pass w/ Conditions, Fail, +
  others)
  • Top 10 filter uses Power BI's built-in Top N filter — no extra DAX needed
  • Slicers pull from your actual dimension tables (dim_date, dim_establishment, dim_facility_type)
